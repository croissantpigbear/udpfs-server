UDPFS Server for OPL-RA (Windows)
=================================

Nothing to install: Python is included.

1. Keep this whole folder together (UDPFS Server.exe, app, python).
   Put it anywhere, for example C:\UDPFS Server.
2. Double-click UDPFS Server.exe.
3. Pick your OPL folder (E:\PS2) - or a disk image - and press Start.
4. First time only: press "Allow through firewall" and say Yes.

If Windows SmartScreen says it "protected your PC": More info > Run anyway.
(The program is not signed.)

The dot turns green when the PS2 talks to the server. Keep the window
open while you play. "Open with Windows" starts it minimized at login,
already serving.
